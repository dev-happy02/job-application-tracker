# 📊 Job Application Tracker

An Excel-based **Job Application Tracker** designed to organize and manage the complete job-search process — from applying for a job to interviews, follow-ups, and offers.

## 🚀 Features

- 📋 Track job applications
- 🏢 Store company and role information
- 🔗 Save job posting links
- 📄 Track resume versions used
- 📌 Track application status
- 👤 Store recruiter/contact details
- 📅 Schedule follow-up dates
- ⏱️ Automatically calculate days since application
- 🚨 Identify overdue follow-ups
- ⭐ Set application priority
- 📊 Track skill-match percentage
- 🎯 Track interviews and interview rounds
- 📈 Dashboard with application analytics
- 📊 Application status visualization
- 🔎 Track job application sources

## 📁 Workbook Structure

| Sheet | Purpose |

## 💡 How to Use

1. Open `Job_Application_Tracker.xlsx`.
2. Go to the **Applications** sheet.
3. Enter the details of every job you apply for.
4. Select the appropriate status from the dropdown.
5. Add a follow-up date when required.
6. Update the application status as you progress.
7. Use the **Dashboard** to monitor your job-search progress.
8. Use the **Interviews** sheet to record interview rounds and results.

## 📌 Application Status

- 🟡 Applied
- 🔵 Follow Up
- 🟢 Interview
- 🟢 Offer
- 🔴 Rejected
- ⚪ Withdrawn

## 🎯 Use Case

This tracker is useful for students, freshers, and professionals who are actively applying for jobs and want to maintain a structured record of their applications.

It can help reduce missed follow-ups and provide a clear overview of the overall job-search process.
